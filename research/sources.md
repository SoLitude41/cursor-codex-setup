# Sources

Research topic: LinkedIn organic content strategy for B2B SaaS

## Collection Methodology

1. Use LinkedIn profile links as expert identity anchors.
2. Use LinkedIn post links as primary examples of organic LinkedIn content, manually collected and pasted verbatim.
3. Use YouTube links as transcript candidates, then collect real transcript text and video metadata (title, channel, publish date) programmatically via the Supadata API (`scripts/collect-youtube-transcripts.ps1`). No transcript text is fabricated, summarized, or edited — it is the API's output, decoded from HTML entities only.
4. Record dates for when sources were added to this repository.
5. Store LinkedIn post notes by author in `research/linkedin-posts/`.
6. Store collected YouTube transcripts by video in `research/youtube-transcripts/`.
7. Store non-LinkedIn/non-YouTube reference material in `research/other/`.

## YouTube Transcript Collection Method

All 10 transcripts were collected on 2026-07-03 by running `scripts/collect-youtube-transcripts.ps1`, which calls the Supadata API (`/youtube/video` for metadata, `/youtube/transcript` for transcript text) for each video ID in `scripts/video-manifest.json`. The Supadata API key is supplied via the `SUPADATA_API_KEY` environment variable at runtime and is never committed to the repository.
