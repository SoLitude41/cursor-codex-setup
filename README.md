# LinkedIn Organic Content Strategy for B2B SaaS

## Objective

Research how experienced B2B SaaS marketers and creators use organic LinkedIn content, then organize source material for later analysis.

## What Has Been Collected

This repository currently contains a first-pass source set for 10 experts. For each expert, the repo records:

- One LinkedIn profile link
- One LinkedIn post link and pasted post text supplied by the project owner
- One YouTube video link as a transcript candidate
- A short annotation explaining why the expert was selected
- Local files for LinkedIn post text/notes and YouTube transcript collection placeholders

No transcript text or research findings have been fabricated. LinkedIn post text currently comes from the project-owner attachment.

## Repository Structure

```text
research/
├── sources.md
├── linkedin-posts/
│   ├── index.md
│   └── [author]/post-01.md
├── youtube-transcripts/
│   ├── index.md
│   └── [expert]-video-01.md
└── other/
```

## Methodology

1. Select experts who actively practice B2B SaaS, content, growth, positioning, demand generation, or audience-building work.
2. Use LinkedIn profiles as identity anchors.
3. Save LinkedIn post links as examples of organic LinkedIn content to review manually.
4. Save YouTube links as transcript candidates.
5. Only add transcript text after confirming transcript availability through YouTube captions/transcript or another legitimate transcript source.
6. Record collection dates, source URLs, and notes in Markdown files.
